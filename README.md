## 📌 Description
**AI Model Marketplace** is a blockchain platform that allows **buying and selling AI models** for **ERC-20 tokens (UNGT)**.
The project uses **smart contracts on Solidity**, **interaction with MetaMask** and **Ethereum blockchain network (local)**.

---

## 🚀 **Functionality**
✔️ **MetaMask connection** – the user can connect the wallet to the marketplace.
✔️ **Display token balance** – the UNGT balance is updated in the interface.
✔️ **Adding AI models** – users can upload their models and sell them for UNGT.
✔️ **Purchase of AI models** – users can purchase AI models by transferring UNGT to the seller.
✔️ **Smart Contract on Ethereum** – all transactions occur through a **smart contract** on the local network.

---

## 🛠 **Technologies**
- **Solidity** – development of smart contracts (ERC-20 and marketplace).
- **Hardhat** – deployment and testing of contracts.
- **Ethers.js** – interaction with the blockchain via the frontend.
- **JavaScript / HTML / CSS** – UI for working with users.
- **MetaMask** – connecting user wallets.
